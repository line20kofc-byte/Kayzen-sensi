# Kayzen Sensitivity V7 — pesquisa grátis sem cartão

A busca online usa **TinyFish Search**, que declara a API de Search gratuita sem cartão de crédito, sujeita a limites de requisições. A publicação usa Netlify Functions; a chave fica apenas em `TINYFISH_API_KEY`, nunca no JavaScript do navegador.

O usuário informa o modelo, escolhe Free Fire ou Free Fire MAX e clica em **Gerar** ou **Pesquisar**. Se houver DPI e sensibilidade explícitos nas fontes indexadas, são exibidos com URLs; quando faltarem informações, o site oferece cinco perfis claramente rotulados como **experimentais**. Vídeos do TikTok não são interpretados automaticamente. No iPhone, PPI físico não é o ajuste `Menor largura` do Android.

**O site não está publicado e não contém sua chave privada.** Veja `COMO_ATIVAR_API.txt` para configurar. Use GitHub conectado ao Netlify para publicar a função (enviar somente HTML pelo Netlify Drop não publica funções).
